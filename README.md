# AEGIS-Rx | Frontend

A web-based interface for a precision space medicine project developed during the NASA Space Apps Challenge.

## Overview

AEGIS-Rx is a clinical decision-support prototype designed to explore personalised health assessment and medication recommendations for astronauts during deep-space missions.

The project addresses the challenges of assessing individual biological responses to radiation exposure and making informed medication decisions when access to medical support on Earth is limited.

## Project Features

The complete application explores three main areas:

- **Astronaut Health Profiling:** Uses individual genomic and health-related information to support personalised assessments.
- **Radiation Exposure Assessment:** Explores gene-expression-based biodosimetry to evaluate biological responses to radiation exposure.
- **Medication Decision Support:** Considers genetic factors, drug interactions and changes in medication potency when generating personalised recommendations.

These components are integrated into a workflow covering different stages of a space mission, from pre-flight preparation to post-exposure recovery.
